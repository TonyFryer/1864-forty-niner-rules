# 1864: Forty-Niner Rules Website

Open `index.html` in a browser. No build tools, server, or external dependencies are required.

Files: `index.html`, `styles.css`, `script.js`, `rules-data.js`, and `assets/`. `rules.json` contains the source transcription as structured data.

Text is sourced from *1864: Forty-Niner — Stand Alone Official Rules, v1.6*. The original document defers unspecified rules to 1861/1867.
